INAMIGOS FOUNDATION — AWARENESS WEBPAGE

Files:
- index.html — main webpage
- style.css — responsive styling

How to run:
1. Keep index.html and style.css in the same folder.
2. Open index.html in Chrome/Edge/Firefox.
3. The page uses official InAmigos event-image URLs, so an internet connection is required for the visuals.

Research used:
- Official website: https://www.inamigosfoundation.org.in/
- Official LinkedIn: https://www.linkedin.com/company/inamigos-foundation/

The content covers the six core initiatives: Seva, Bachpanshala, Jeev, Udaan, Prakriti and Vikas, plus official impact figures and public events listed by InAmigos.
